`Televideo` è un programma che permette di cercare nel palinsesto dei canali televisivi italiani i programmi di interesse per l'utente.

Il programma è disponibile in due versioni:
- Python (`Televideo_python\Televideo.py`)
    - richiede `Python 3.8+` e le librerie `tkinter` e `aiohttp` 
- C# (`Televideo_c_sharp`)
    - compatibile solo con Windows 10 e 11
    - file eseguibile `Televideo.exe` pronto all'uso incluso nella release


## Funzionamento
Il programma permette di cercare film, programmi e serie nel palinsesto dei principali canali televisivi italiani fino a 7 giorni a partire dalla data attuale.
